# Juego Shooter

## Descripción

Juego Shooter es un videojuego desarrollado en Unity donde el jugador debe eliminar enemigos y sobrevivir a diferentes oleadas.

## Características

- Movimiento del jugador
- Sistema de disparo
- IA de enemigos
- Sistema de vida
- Menú principal
- 1 Mapa

## Tecnologías

- Unity 6
- C#
- Git
- GitHub

## Requisitos

- Unity 6
- Visual Studio o Visual Studio Code
- Git

## Instalación

```bash
git clone https://github.com/XFaiderrrrr/Juego_Shooter.git
```

1. Abrir Unity Hub.
2. Agregar el proyecto.
3. Esperar a que Unity importe los archivos.

## Controles

 Acción = Tecla 

 Mover = WASD 
 Disparar = Click izquierdo 
 Apuntar = Click derecho 
 Saltar = Espacio 
 Pausa = Esc
